Embedding remote notarization directly into your SaaS platform, title management software, or fintech application eliminates friction for your end users. The **BlueNotary REST API** and Webhook infrastructure provide modern engineering teams with all the tools needed for frictionless document automation.

## Key Capabilities of the BlueNotary API

- **Session Creation:** Programmatically upload documents, designate signers, and trigger automated verification invites.
- **Dynamic Field Placement:** Inject signature tags, date fields, initials, and notary stamp coordinates via coordinates or text anchor tags.
- **Real-Time Webhooks:** Receive instant HTTPS notifications when signers complete KBA, join calls, or finalize signed packages.
- **Automated Document Retrieval:** Instantly download tamper-evident PDFs, audit logs, and session recordings directly into your internal S3 buckets.

## Authentication and API Keys

All requests to the BlueNotary API are secured via Bearer token authorization:

```http
GET /api/v1/sessions
Authorization: Bearer YOUR_SECRET_API_KEY
Content-Type: application/json
```

Always store your API secret securely in environment variables and never expose client-side secrets in browser-rendered code.

## Step-by-Step Integration Lifecycle

1. **Upload Document:** Post your PDF binary or URL to generate an immutable document asset ID.
2. **Configure Signers & Notary Options:** Specify whether to use your own in-house on-demand notaries or tap into the 24/7 BlueNotary certified notary network.
3. **Dispatch Signing Invitations:** The platform automatically handles email delivery, SMS reminders, and KBA verification links.
4. **Capture Webhook Event:** Listen for `session.completed` to trigger your backend downstream processes, database updates, or customer receipts.
