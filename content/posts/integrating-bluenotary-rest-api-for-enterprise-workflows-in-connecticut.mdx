Automate document signing and verification workflows with the BlueNotary REST API and Webhook engine.

## Core API Features

- Instant session creation with automated signer invites.
- Dynamic document tagging for signature, initials, and stamp coordinates.
- Real-time webhook notifications for session status changes.
- Automated document archiving into enterprise cloud buckets.
